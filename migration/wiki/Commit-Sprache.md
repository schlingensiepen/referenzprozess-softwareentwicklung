# Commit-Sprache

**Entscheid OFFEN** — Frage im Fragen-Block der
Migration (MIGRATION.md Phase 1). Vorschlag des
Agenten dort: **für die Dauer der Migration die
bisherige Regelung des Projekts beibehalten** und
die reguläre Sprach-Frage (Variante A Projektsprache
/ B Sprache folgt Artefakt / C Englisch) **am Ende
der Migration** erneut stellen — Sprach-Wechsel
während der Migration würde Transformation und
Übersetzung vermischen.
