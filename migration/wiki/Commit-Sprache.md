# Commit-Sprache

**Entscheid OFFEN** — Frage im Fragen-Block der
Migration (`_template/migration/MIGRATION.md`
Phase 1). Vorschlag des Agenten dort: für die Dauer
der Migration die bisherige Sprach-Regelung des
Projekts beibehalten — ein Sprach-Wechsel würde
Transformation und Übersetzung vermischen. Das
reguläre Menü (Variante A Projektsprache / B Sprache
folgt Artefakt / C Englisch; Vorauswahl bei
Codeprojekt-Prozessen wie SP-1/RP-1: B) stellt die
Migration in Phase 5. Der Entscheid wird hier gebucht
und gilt ab dann für alle Commits (MasterPrompt
§6.2).
