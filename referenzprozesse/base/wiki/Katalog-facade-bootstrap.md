# Katalog-facade-bootstrap

Einzeltyp-Eintrag: Infrastruktur-Typ der
Template-Quelle (nie kopiert).

### facade-bootstrap

- **Zweck:** Einmal-Anweisungen je Fassade in
  `_template/referenzprozesse/<P>/bootstrap/`
  (Wiki.md §11 „`bootstrap/`“); beim Init/Merge bzw.
  bei Reaktivierung
  aus der Template-Quelle abgearbeitet
- **Klasse:** außerhalb
- **Pflichtfelder:** `type: facade-bootstrap`,
  `fassade` (Name der Fassade), `prozess`
- **Beispielname:** `bootstrap/Katalog.md`
- **Ablage:** `referenzprozesse/<P>/bootstrap/`;
  Template-Quelle, nie ins Anwender-wiki kopiert
  (Wiki.md §11.3 Schritt 5).
